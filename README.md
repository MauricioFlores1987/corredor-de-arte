# 🎨 Corredor de Arte

Juego de plataformas 2D (Phaser 3). 10 etapas, jefe final, minijuego de lienzos y cinemática de cierre.
Funciona en PC (teclado) y celular (botones táctiles en pantalla). Ponlo el celular en horizontal.

## Archivos (deben quedar juntos en la misma carpeta)
- `index.html` – el juego
- `phaser.min.js` – motor del juego (incluido, no necesita internet)

## Publicar en GitHub Pages (gratis)
1. Entra a github.com → botón **+** → **New repository**. Nombre: `corredor-de-arte`, marca **Public** → **Create repository**.
2. En la página del repositorio pulsa **uploading an existing file**.
3. Arrastra (o elige) `index.html`, `phaser.min.js` y `README.md` → **Commit changes**.
4. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/(root)** → **Save**.
5. Espera 1–2 minutos y recarga. Tu juego estará en: `https://TU-USUARIO.github.io/corredor-de-arte/`
